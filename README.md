# 贝瑞基因 D3V 策略 · 每日信号自动更新

针对 A 股贝瑞基因（000710）的 D3V 趋势策略：每个交易日收盘后增量更新数据、计算信号，并通过 GitHub Actions 自动推送到本仓库。

> ⚠️ 本项目仅供技术研究与学习，**不构成任何投资建议**；策略历史表现不代表未来收益，实盘前请自行评估风险。

### 调仓执行规则

| 动作 | 含义 | 执行 |
| --- | --- | --- |
| 买入/加仓至目标仓位 | 明日信号满足进场条件 | 次日开盘买入「目标仓位 − 当前仓位」差额 |
| 持有 | 信号延续 | 不操作 |
| 卖出/清仓 | 任一进场条件失效 | 次日开盘卖出全部持仓 |
| 空仓等待 | 进场条件未满足 | 不操作 |

- 成交约定：次日开盘成交；大跳空 ≥3% 时等回撤——高开 ≥3% 不追买，等价格回落至昨收价成交；低开 ≥3% 不杀跌，等反弹至昨收价成交；当日未成交则顺延。
- 仓位计算：目标仓位 = 信号 × min(40% / 20 日年化波动率, 100%)，永不满仓超配，每次只补目标与当前之差。
- 数据缺日：某标的缺最新交易日数据时，该门控强制关闭（保守处理）。

### 历史回测（retrace 口径：次日开盘+大跳空≥3%等回撤，成本 0.1%/边即往返0.2%，可复现）

> **统计显著性披露（DSR）**：经 594 点参数网格的多重试验校正，策略 PSR vs 0 ≈ 1.0（正收益几乎确定），但 DSR 均低于 0.95（2013+ 0.94、2017+ 0.62、2021+ 0.51）——"跑赢参数搜索运气"不显著，回测收益应视为乐观上界。方法与完整分析见 [docs/methodology.md](docs/methodology.md)。

### 方法论改进试行结果（2026-08-07，详见 [docs/methodology.md](docs/methodology.md)）

- **滚动 walk-forward 已试，不采用**：10 折×594 点逐年重训，聚合 +50.7%/Calmar 0.30，远劣于固定 D3V 同窗口 +523.3%/Calmar 1.46（IS 按 Calmar 选参偏向保守低仓，OOS 几乎不交易）→ 维持参数先验固定；
- **成交约束已补**：`--limit-block` 强制一字板不可成交（一字涨停只拦买入、一字跌停只拦卖出），验证与 retrace3% 默认结果完全一致（+529.5%/-14.3%）；停牌日数据源直接省略、T+1 无同日往返天然满足；
- **试验登记簿已建**：`data/experiments_log.csv` 记录全部历史尝试与新试验，DSR 的 n_trials 可追溯。

## 快速开始

```bash
pip install -r requirements.txt

# 每日信号（增量更新数据并计算）
python3 code/daily_signal.py

# 只重算信号，不更新数据
python3 code/daily_signal.py --no-update

# 本地一键：更新数据 + 算信号 + 提交推送 GitHub
./run_daily.sh
```

## 复现回测

```bash
python3 code/optimize.py data/sz000710_daily_qfq.csv \
  --fasts 3 --slows 20 --rsi-ceiling 80 --stops none --vol-target 0.4 \
  --adx 0 --sector-csv data/sh512010_daily.csv --sector-ma 20 \
  --extra-csv data/sz399006_daily.csv --extra-ma 30 --trend di \
  --turnover-range 0.008,0.10 --execution retrace --retrace-gap 0.03 \
  --cost 0.001 --split 2017-01-01        # 追加 --limit-block 启用一字板阻断

# 滚动 walk-forward（10折×594点，含聚合DSR）
python3 code/walk_forward.py data/sz000710_daily_qfq.csv \
  --sector-csv data/sh512010_daily.csv --extra-csv data/sz399006_daily.csv
```

- 个股：东财 `stock_zh_a_hist` 优先，失败回退新浪 `stock_zh_a_daily`，前复权，含换手率
