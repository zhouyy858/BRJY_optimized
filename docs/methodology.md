# D3V 策略 · 方法论评审与统计检验（2026-08-07）

本文档回答三个问题：本项目开发的代码在方法上是否站得住脚、与主流开源量化/AI 开发项目相比差在哪里、以及统计上"收益是真的还是参数搜索运气"。

> ⚠️ 本文档只讨论研究方法与统计口径，不构成投资建议；所有历史回测数字不代表未来收益。

## 1. 评审结论摘要

1. **发现并修复一处窗口收益归一化 bug**：`optimize.py` 样本外统计把裸净值相除当成收益率，导致 README 与 `optimized_params.json` 中的"连续运行口径"数字被大幅夸大（2017+ 从 +1677% 修正为 +529.5%）。修复后连续运行与冷启动两口径一致。
2. **新增 DSR 统计检验模块**（`code/deflated_sharpe.py`，Bailey & López de Prado 2014），对策略做多重试验校正。
3. **DSR 的诚实结论**：策略几乎确定是正收益（PSR vs 0 ≈ 1.0），但"跑赢从 594 个参数变体里挑最好"的运气基准**不显著**（2013+ DSR 0.94、2017+ 0.62、2021+ 0.51，均低于 0.95），MinTRL 需要数十年乃至上万年样本才能证明显著。历史收益的显著性无法成立，回测数字应视为乐观上界而非预期值。
4. 项目在**时间因果、成交假设、成本、样本内外划分**上已具备业内基本纪律；差距主要在**试验过程记录、滚动重训、涨跌停/停牌/T+1 等成交约束、以及统计显著性披露**。

## 2. 严重发现：窗口归一化 bug（已修复）

**位置**：`code/optimize.py` 样本外统计 `_oos()`。

**错误公式**：

```python
norm_eq = s / base - 1   # s、base 是"净值-1"的累计收益，直接相除会把负起点放大
```

**正确公式**：

```python
norm_eq = (1 + s) / (1 + base) - 1
```

**为什么会夸大**：2017 年初净值约为 -54%（`base≈0.4613`），把后续净值直接除以 0.4613，等于把"从 -54% 起步"误当成"从 0 起步"，收益被放大约 2.9 倍；最大回撤同样失真（用裸净值算回撤，分母基准取决于任意窗口起点）。

**影响范围（全部来自 README 旧数字）**：

| 区间 | 旧数字（bug） | 修正后（正确口径） |
| --- | --- | --- |
| 2017+ | +1677% / -29.1% / Calmar 1.26 | **+529.5% / -14.3% / Calmar 1.55** |
| 2021+ | +449% / -13.0% / Calmar 2.86 | **+269.1% / -8.9% / Calmar 3.10** |
| 2013+ | +820% / -14.3% / Calmar 1.44 | +820.0% / -14.3% / Calmar 1.44（不受影响，起点净值恰为 0） |
| 样本外 2019-2021 | +1040% / -29.1% | +435.2% / -14.3% |
| 样本外 2022+ | +434% / -10.9% | +262.8% / -8.9% |

**修复后**：连续运行口径与冷启动口径（窗口内从零重算指标）恰好一致——2017+/2021+ 窗口起点本就空仓、指标预热期无信号，两口径路径相同。

**对策略结论的影响**：修正后 2017+ 仍跑赢买入持有（+529.5% vs -82.9%），回撤反而更好看（-14.3% vs -29.1%）；被砍掉的是被夸大的部分，不是策略本身。

## 3. DSR 统计检验（多重试验校正）

### 3.1 为什么需要

参数网格搜索等价于做 N 次独立试验、然后汇报最好的那一个。N 越大，"运气最好"的 Sharpe 就越高。直接看选中参数的 Sharpe 存在选择偏差。Bailey & López de Prado (2014) 提出的 Deflated Sharpe Ratio (DSR) 就是干这件事的：

- **PSR(SR\*)**：观测 Sharpe 超过"N 次试验期望最大 Sharpe（SR\*）"的概率；
- **MinTRL**：需要多少期数据才能以 95% 置信度证明 SR > SR\*。

实现要点（`code/deflated_sharpe.py`，已与论文示例对拍）：每期 Sharpe 口径；峰度用非超额峰度（正态=3）；SR\* 用欧拉-马歇罗尼常数近似期望最大；DSR ≥ 0.95 视为通过 5% 显著性。

### 3.2 试验规模（n_trials 的诚实取值）

- **正式网格 594 点**：fasts {3,5,10,20,30} × slows {20,30,60,90,120}（fast<slow）× RSI {无,70,80} × ATR止损 {无,3,5} × 波动率目标 {无,0.25,0.4}，结构过滤（+DI、医药ETF>MA20、创业板>MA30、换手 0.8-10%）固定；
- **项目全程探索量 2000-5000**：把多轮重训、门控变体、指数选择等结构性尝试都算进去的真实上限。项目目前没有试验登记簿，真实 N 只能估算——按保守口径取 2000 和 5000 做敏感性。

试验 Sharpe 分布在**同一窗口、同一成交假设**下计算（窗口级分布，避免全样本低估试验方差）。

### 3.3 结果

| 窗口 | 观测 SR（年化） | SR\*（年化，N=594） | DSR @ N=594 | DSR @ N=2000 | DSR @ N=5000 | MinTRL（N=594） |
| --- | --- | --- | --- | --- | --- | --- |
| 2013+（n=3000） | 1.31 | 0.95 | 0.936 ❌ | 0.859 ❌ | 0.778 ❌ | 3519 日 |
| 2017+（n=2318） | 1.37 | 1.29 | 0.617 ❌ | 0.400 ❌ | 0.262 ❌ | 70541 日 |
| 2021+（n=1355） | 1.57 | 1.56 | 0.505 ❌ | 0.289 ❌ | 0.169 ❌ | 不可达（约 2053 万日） |

（试验 Sharpe 分布与选中策略同为 retrace 成交口径、同一窗口，数值以 `code/deflated_sharpe.py` 为准。）

**解读**：

- PSR vs 0 ≈ 1.0：策略期望收益为正几乎确定，趋势+门控框架本身不是噪音；
- 但它的 Sharpe 处于"594 个参数里挑最好"的运气范围内，2017+/2021+ 连 N=594 都不显著；
- MinTRL 70541 日 ≈ 282 年（2017+，N=594）：单只股票的历史数据永远无法在统计上证明这个 Sharpe；
- DSR 只校正参数内选择，不校正"多轮重训"造成的结构性数据窥探——真实显著性只会更低。

**这不是否定策略，而是把回测收益从"预期值"降级为"乐观上界"**。对单标的、单策略项目的正确用法是：接受历史显著性不可证，把功夫放在先验参数纪律、经济学理由和真实样本外跟踪上。

## 5. 改进建议试行结果（2026-08-07）

优先级清单已逐项试运行，结论如下（完整登记见 `data/experiments_log.csv`）：

1. **试验登记簿** ✅ 已建立 `data/experiments_log.csv`（15 条：历史尝试按 git/文档反推 + 新试验即时登记），DSR 的 n_trials 从估算变为可追溯；
2. **滚动 walk-forward** ⚠️ 已试运行：10 个年度折点 × 594 点网格（`code/walk_forward.py`），IS 按 Calmar 选参、次年样本外验证。聚合结果 **+50.7% / Calmar 0.30 / 33 笔交易**，而固定 D3V 同窗口 **+523.3% / Calmar 1.46 / 81 笔**——滚动重训显著劣于固定参数。原因：IS 用 Calmar 会偏向保守低仓参数（几乎每折都选 vol=0.25、无 RSI），样本外几乎没有交易。**结论：单标的采用参数先验固定（第 5 条），不做滚动重训**；
3. **成交约束补强** ⚠️ 已试运行：新增 `--limit-block`（一字涨停只拦买入、一字跌停只拦卖出，含方向判断，仅 retrace 口径）。验证结果：与默认 retrace **完全一致**（+529.5%/-14.3%）——retrace3% 规则本就把一字板买入按"大高开未回落→顺延"拦截、一字板卖出按开盘成交（与实盘一致）；停牌日被数据源直接省略天然跳过；T+1 因策略无同日往返交易天然满足。保留 `--limit-block` 为显式强制选项，防 retrace_gap 调大后漏检；仍缺滑点模拟；
4. **实盘跟踪表** ⚠️ 部分完成：每日信号/目标仓位已由 `daily_signal.py` 写入 `last_signal.json` 与 `signal_log.csv`；缺实盘成交回填列（需实盘后人工或券商接口回填）；
5. **参数先验固定** ✅ 经 WFA 验证后采纳：结构参数（MA3/20、RSI80、+DI、三大门控、换手 0.8-10%、vol0.4、retrace3%）定稿，不再因历史收益调整；任何改动必须先登记 `experiments_log.csv`；
6. **每次重训附 DSR** ✅ `deflated_sharpe.py` 已落地；WFA 聚合路径 DSR=0.18（N=594）/ 0.07（N=5940），同样不显著——与单窗口结论一致，进一步支持"历史显著性不可证、靠实盘跟踪验证"的定位。

**综合结论**：以上试验不改变 D3V 定稿参数；回测数字的定位是乐观上界。真正的验证来自 2026-08 起的实盘跟踪表。

## 6. 盘中实时决策试点（2026-08-07）

需求：收盘前（14:30/14:45）用盘中实时数据计算信号、当场买卖，看能否优化结果。实现 `code/intraday_backtest.py`：baostock 5 分钟前复权（2020-01-02 起有分钟线），个股 MA/RSI/DI 用"截至 T-1 日线 + T 日盘中价/盘中高低"实时计算；板块/创业板/换手/波动率门控用 T-1 已知值；成交价=决策时点分钟线收盘价，买卖同规则，成本 0.1%/边，无未来函数。

**窗口 2020-01-02 ~ 2026-08-06 对比**：

| 模型 | 收益 | 最大回撤 | Calmar | 交易数 |
| --- | --- | --- | --- | --- |
| 官方 retrace（CSV 口径，连续运行） | +430.0% | -14.3% | 2.11 | — |
| 官方 retrace（baostock 同源基线） | +410.6% | -14.3% | 2.06 | 45 |
| 盘中 14:30 决策 | +332.3% | -10.2% | 2.53 | 63 |
| 盘中 14:45 决策 | +291.5% | -11.0% | 2.18 | 63 |
| 盘中 14:30 网格最优 Calmar（3/20/RSI80/vol0.25，样本内） | +175.7% | -6.5% | 2.67 | 63 |
| 盘中规则触发（无时钟，信号变即成交，T+1） | +210.8% | -23.3% | 0.84 | 312 |
| 规则触发 + 连续确认 24 bar（纯规则最优） | +239.0% | -15.4% | 1.38 | 160 |
| 价格触发 pct2 + 门控（12 组中收益最优） | +249.8% | -25.5% | 0.86 | 225 |
| 价格触发 orb30 + 门控 | +118.3% | -22.2% | 0.59 | 217 |
| 价格触发 ma5 无门控（最差） | -97.5% | -98.2% | -0.45 | 3167 |

**结论**：

1. 盘中实时决策**不提高收益**（14:30 -19%、14:45 -29% vs retrace），盘中噪音导致更多假信号（63 vs 45 笔）；
2. 但**显著降回撤**（-10.2% vs -14.3%），14:30 时点 Calmar 2.53 > 2.06，属于"用收益换回撤"的风险权衡；
3. 90 点网格探索（样本内）中，现有 D3V 参数（3/20/RSI80/vol0.4）仍是盘中口径下总收益最高；降 vol 至 0.25 可把 Calmar 提到 2.67 但收益减半；
4. **规则触发（无时钟参数）不采用**：每个 5 分钟 bar 实时算信号、变了就成交，312 笔交易、+210.8%/-23.3%/Calmar 0.84，全面劣于固定时点与日线口径——盘中早期信号噪音大，T+1 使假信号被迫隔夜扛单；纯规则确认（连续 N 根 bar）可减交易次数但最好也仅 +239.0%/-15.4%/Calmar 1.38。**"固定时点"的价值不在时钟，而在其隐含的"全天信息接近完整才决策"规则**；规则触发版证明了越早动作越差；
5. **纯价格触发规则（用户要求"触发即买卖、不看收盘价"）不采用**：6 条规则 × 门控开关共 12 组全部劣于 retrace 基线（+410.6%/-14.3%/Calmar 2.06）。最优为 pct2+门控（上破昨收+2%做多/下破昨收-2%离场）+249.8%/-25.5%/Calmar 0.86/225 笔；orb30（开盘 30 分钟区间突破）仅 +118.3%；vwap/ma5 均线类换手 700+ 笔、回撤大。**门控是价格规则的生死线**：带 D3V 门控（板块/创业板/换手 T-1 值）的 6 组全部优于同规则不带门控，不带门控的 ma5/vwap 接近亏光（-97.5%/-68.7%）——价格触发只提供"何时买/卖"的时机信号，**方向判断仍依赖 D3V 大盘/板块门控**；"盘中越早动作收益越差"再次被验证，维持日线 retrace 口径不动；
6. **局限**：板块门控用 T-1 值（未取 ETF/创业板分钟线）；成交为分钟线收盘价市价假设，未计滑点/冲击/涨跌停排队；窗口仅 2020+；参数未针对盘中口径重新做样本外验证。若正式切换盘中执行，需按 WFA+DSR 流程重做参数验证。

**结论**：

1. 相关性最强的是**基因测序板块**（0.62/0.68），印证"贝瑞基因属于基因测序板块"的直觉；创业板指相关性只有 0.45/0.32，用户的怀疑有数据支撑；
2. 但**强相关板块作为门控反而更差**：换成基因测序门控后 2017+ 收益从 +529.5% 掉到 +375.4%、回撤从 -14.3% 扩大到 -16.7%；AND/OR 组合、智能医疗、无门控均无法超越创业板门控；
3. 机制解释：基因测序板块指数**包含贝瑞基因自身**（高权重），高相关性 = 自指/冗余信息——它基本是"个股自身趋势的第二份拷贝"，叠加在 MA/RSI/DI 之上不增加新信息，反而放大洗盘；创业板指相关性低正是因为它是**正交的**——提供"成长股市场风险偏好"这一独立维度，过滤掉个股自身指标看不到的系统性风险；三个门控 ON 天数占比都约 50%，差异不在松紧，在过滤了哪些日子；
4. AI应用相关性最高（0.728）但板块 2026-01 才发布，历史不足 1 年，无法验证门控有效性，按规则不可用于回测；
5. **维持创业板门控不变**。数据与代码已入库：`data/ths_gene_sequencing_daily.csv`（基因测序板块指数，随 daily_signal 每日更新）；`code/daily_signal.py` 新增 `SECOND_GATE = "cyb" | "gene"` 一行切换，切换需用户确认后生效。
